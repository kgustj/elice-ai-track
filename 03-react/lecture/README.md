# 엘리스 AI 트랙 · React 강의 실습

> 엘리스 AI 트랙 4기 · 2022.03 ~ 05 · React (Create React App)

| 폴더 | 내용 |
| --- | --- |
| train1st ~ train4th | 1~4차 실습 과제 |
| live | 라이브 수업 코드 |
| context | Context API 실습 |
| examples | 사용자 카드·수정 폼·로그인 폼 예제 컴포넌트 |
| 0309 | 3/9 백엔드 보강 수업 (json-server) |
| reducer | useReducer 실습 |
| context-api | Context API 실습 (context와 다른 버전) |
| react-app | React 시작 (Create React App) |

대부분의 폴더는 따로 실행하는 React 앱입니다.

    cd train1st
    npm install
    npm start

> `reducer`는 원본 GitLab에서 내용 없이 링크만 올라가 있었는데, `elice-ai4-frontend` 저장소에 있던 실제 코드로 채웠습니다. `context-api`, `react-app`도 그 저장소에서 옮겨 왔습니다. 같은 문제로 비어 있던 `instagram`은 코드가 남아 있지 않아 지웠습니다.
