# gitlab 연습하기

### 프로젝트에 대비하여 gitlab 기능들을 알아보고, 한 번씩 사용해 봅니다.
### 아래는 대표적인 마크다운 문법 예시 연습입니다.

1. **강조** 강조없음 => 두 개의 ** 사이에 글자를 넣으면 강조입니다.
2. <br/> 을 넣으면 빈 줄이 생겨서, 다음 줄로 넘어갑니다.
3. <hr /> 을 넣으면 수평 줄이 생깁니다.
4. - 을 넣으면 검은색 점이 생깁니다.
5. - 아랫줄에 탭해서 -을 또 쓰면, 흰색 점이 생깁니다.
- 첫 번째
    - 두 번째
6. > 을 넣으면 연한 색 글씨가 써 집니다.
7. 캡처 사진을 ctrl+c ctrl+v로 붙여넣기 할 수 있습니다.
![image.png](./image.png)
8. #의 경우 html의 h1~h4와 비슷합니다. #쓰고 한 칸 띄고 글씨를 쓰면 됩니다.
