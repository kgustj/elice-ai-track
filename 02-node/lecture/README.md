# 엘리스 AI 트랙 · Node.js 강의 실습

> 엘리스 AI 트랙 4기 · 2022.02 ~ 05 · Node.js, Express

| 폴더 | 내용 |
| --- | --- |
| nodebird | SNS 클론 NodeBird: MySQL(Sequelize), Passport 로그인(로컬·카카오), 게시글·해시태그 |
| train | 게시판 실습: MongoDB(Mongoose) 회원·게시글·댓글, Passport |
| live | 라이브 수업: Express 라우팅, 쿠키, Pug 템플릿 |
| pagination | 페이지네이션 실습 (package.json만 있음) |
| ai4backend1nd | Node 기초: 모듈, 파일 읽기(동기·비동기) |
| ai4backend2nd | Express 시작: 라우팅, Pug |
| ai4backend4th | JWT 로그인 API |
| ai4backenddiary | 일기장: MongoDB 스키마, 댓글 |
| rest-api-example | DB 없이 만든 메모 REST API |

`ai4backend*`, `rest-api-example`은 원래 `elice-ai4-backend` 저장소에 있던 실습입니다.

각 폴더는 따로 실행하는 앱입니다.

    cd nodebird
    npm install
    npm start
