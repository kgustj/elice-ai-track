# 엘리스 AI 트랙 · Node.js 강의 실습

> 엘리스 AI 트랙 4기 · 2022.02 ~ 05 · Node.js, Express

| 폴더 | 내용 |
| --- | --- |
| nodebird | SNS 클론 NodeBird: MySQL(Sequelize), Passport 로그인(로컬·카카오), 게시글·해시태그 |
| train | 게시판 실습: MongoDB(Mongoose) 회원·게시글·댓글, Passport |
| live | 라이브 수업: Express 라우팅, 쿠키, Pug 템플릿 |
| pagination | 페이지네이션 실습 (package.json만 있음) |

각 폴더는 따로 실행하는 앱입니다.

    cd nodebird
    npm install
    npm start
